void main() {
  final scores = {'Ada': 95, 'Linus': 88};
  for (final e in scores.entries) {
    print('${e.key} scored ${e.value}');

  // Null safety built in
  print(scores['Grace'] ?? 'not enrolled');
}

          💬 FAQ
          
Questions, answered

        

        

          

            Is Dartic free?
            
Yes. All lessons, quizzes and the code runner are free to use.

          

          

            Do I need any programming experience?
            
No. The Dart fundamentals path starts from zero, explaining every concept with everyday analogies before showing the code.

          

          

            Does the code really run on my phone?
            
Yes. Dartic includes a Dart interpreter, so programs you write in the editor run directly on your device.

          

          

            Do I need an account?
            
You can start the Dart course as a guest. Signing in with Google or Apple unlocks algorithm practice and the data structures course, and syncs your progress across devices.

          

          

            Is this useful for Flutter developers?
            
Absolutely. Flutter apps are written in Dart, so a solid grasp of the language (async code, classes, collections, null safety) makes everything in Flutter easier.

          

          

            Is Dartic open source?
            
Yes. The app and this website live on GitHub, and contributions to lessons, quiz questions and features are welcome.
