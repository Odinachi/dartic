          04 FAQ
          
Questions, answered

        

        

          

            Is Dartic free?
            
Yes. All lessons, quizzes and the code runner are free.

          

          

            Do I need any programming experience?
            
No. The Dart path starts from zero and explains each idea with an everyday analogy before showing any code.

          

          

            Does the code really run on my phone?
            
Yes. Dartic ships with a Dart interpreter, so what you write in the editor runs on the device, even offline.

          

          

            Do I need an account?
            
Not for the Dart course. Signing in with Google or Apple unlocks the data structures course and algorithm practice, and syncs your progress across devices.

          

          

            Is this useful for Flutter developers?
            
Very. Flutter apps are written in Dart, so a solid grip on async code, classes, collections and null safety makes Flutter much easier.

          

          

            Is Dartic open source?
            
Yes. The app and this site are on GitHub. Fixes, lessons and quiz questions are welcome.
